# Death Pause

Opens the normal pause menu the moment you die, instead of instantly respawning.

- **Resume** respawns you exactly like vanilla would have.
- **Restart / Practice / Quit** work as usual.
- Toggle separately for normal and practice mode, with an optional delay so you can watch the death effect first.

Keep GD's *Auto Retry* option **on**; with it off you'd get the retry screen as well.
